It does not just say "spam".

A score with no reasoning is a number you either believe or ignore. Everything below is evidence you can check.

Attribution

Exact SHAP, not a guess

Every point of the score is attributed to a specific feature using exact TreeSHAP. The attributions sum to the prediction — asserted to 1e-6 in the test suite, so the explanation cannot drift from the model.

Language

Any language

A scam written in Hindi or Spanish is detected, translated, then scored by the same English lexicons. Detection runs locally with no model and no API call.

Spanish phish: 20.0 LOW → 48.5 MEDIUM

Vision

Text hidden in images

Scam text pasted into a PNG is invisible to every word-based scanner. QR codes are decoded locally and exactly; image text is transcribed and scored.

image-only phish: 1.5 benign → 65.0 flagged

Identity

Memory
