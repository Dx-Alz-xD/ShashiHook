Privacy

A tool that reads your mail owes you a specific answer, not a general one.

What is stored

DataWhereProtection
Login passwordLocal databaseArgon2id hash — not recoverable, by design
Mailbox app passwordLocal databaseAES-256-GCM, key held in a separate 0600 file
Sender historyLocal file, 0600Counts and timestamps, no message text
Writing-style profilesLocal file, 0600Rates and averages, no message text
Thread indexLocal fileShort hashes, no readable content

The mailbox password is encrypted, not hashed

This is the one place we cannot use a one-way hash: the scanner has to present that password to your mail server on every connection. So it is encrypted and recoverable.

What that means for you. Anyone who obtains both the database and the key file can read your mailbox password. A stronger design would derive the key from your login password so it is only readable while you are signed in — and that would break the background watch daemon, which reconnects while nobody is signed in. This build chose the daemon. Use a provider app password scoped to mail, which you can revoke without touching your main account.

What leaves this machine

  • Your mail server — to fetch mail. Unavoidable.
  • Gemini or Groq — only for written explanations, translation and reading text inside images. Message content is sent for those features. Set LLM_TRANSLATE=0 and LLM_READ_IMAGES=0 to stop it.
  • VirusTotal — attachment hashes only, and only if you add a key. A hash is not the file.
  • Breach lookup — the first five characters of a hash, never your address. The service cannot tell which account was checked.

Scoring itself — models, rules, SHAP, similarity search, stylometry — is entirely local. No analytics, no telemetry, no tracking of any kind.

The demo account

The demo account is shared and connected to the project's own test mailbox. Anything visible there is visible to every visitor. Do not connect a real mailbox to it.

Deleting your data

Disconnect the mailbox in Settings to erase the stored credential immediately. Deleting artifacts/users.json removes all accounts.
