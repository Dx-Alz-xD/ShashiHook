About ShashiHook

Engine: ArnosAI

ShashiHook reads a mailbox and explains what it finds. The design goal was never a higher accuracy number — it was that a person reading a verdict can check it.

How a message is scored

Two models run in parallel: one over 163 structural features, one over the wording. An explicit blender combines them. They are kept separate rather than stacked so that SHAP attribution stays faithful — a stacked model's explanation describes the stack, not the evidence.

On top of that sit 32 deterministic rules. Each one encodes a detection precise enough to set a floor the model cannot pull below, and each was validated against 15,103 held-out messages before it was allowed to fire.

The probability is then re-expressed for the base rate where it is deployed. A model trained on a corpus that is 49% malicious will call an ordinary inbox a disaster unless you correct for that; doing so took false positives on a real mailbox from 69 in 150 to 0 in 150.

Severity is declared, not learned

No corpus carries severity labels, so inventing a learned severity would be inventing a number. Instead there is a published rubric:

100 × intent × (0.50·impact + 0.30·exploitability + 0.20·targeting) + escalators

Every message shows its own arithmetic with the values substituted in.

What it deliberately does not do

BuiltMeasuredDecision
URL classifier0.985 AUC held out, 93% false positives on real mailNot wired in
PE malware classifier0.9998 AUC — classes came from different collectionsRemoved
Job-scam classifier0.99 AUC — learned job categories, not deceptionNot used

Those datasets were kept as measuring instruments instead. The malware corpus now supplies an entropy baseline, so an attachment can be reported as "higher entropy than 99.5% of legitimate Windows binaries" rather than a number nobody can interrogate.

The language model cannot move a score. Gemini and Groq write explanations, translate foreign mail and read images. The verdict, severity and attack vector come from measurable evidence. If a model could move the number, an attacker who writes well could argue their way past the filter.

Where the analysis runs

The engine is Python — LightGBM, SHAP, scikit-learn — and runs on the machine serving this page. Mail is fetched directly from your provider. The only outbound calls are to your mail server, and to a language model when you ask for a written explanation.
